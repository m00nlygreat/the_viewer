# 컴포넌트 작성 규칙

- React 함수형 컴포넌트를 사용하고, 컴포넌트 이름과 파일명은 `PascalCase`로 맞춘다.
- 컴포넌트는 하나의 UI 역할을 맡는다. 반복되는 UI나 독립적으로 복잡해진 영역은 별도 컴포넌트로 분리한다.
- 데이터는 props로 받고, 변경 요청은 `onChange`, `onSave` 같은 콜백으로 전달한다. props와 상태는 불변으로 다룬다.
- 상태는 필요한 컴포넌트 가까이에 한 번만 둔다. 계산 가능한 값은 렌더링 중 계산하고, Effect는 외부 시스템과의 동기화에 사용한다.
- 파일 파싱·직렬화는 UI와 분리한다. 파일 접근과 Chrome/PWA API 호출은 별도 모듈로 두고 공통 UI에서 직접 호출하지 않는다.
- PWA와 확장 프로그램은 공통 UI를 공유한다. 데스크톱과 모바일은 반응형 레이아웃으로 대응한다.
- 버튼·입력 등은 의미에 맞는 HTML 요소를 사용하고, 키보드 조작과 입력 레이블을 제공한다.
- 파일에서 읽은 HTML은 정제한 뒤 지정된 렌더러에서 표시한다. Markdown과 이메일 렌더링에도 같은 기준을 적용한다.
