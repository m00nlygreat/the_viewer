# 개인정보 처리 안내

The Viewer는 사용자가 연 파일을 브라우저에서 해석하고 편집합니다. 파일 본문·연락처·일정·첨부를 앱 서버나 분석 서비스로 보내지 않습니다.

## 기기 내 저장

작업 복구가 켜져 있으면 열린 문서의 원본 바이트와 편집 상태, 테마 설정을 IndexedDB에 저장합니다. 설정에서 복구를 끄면 저장된 작업 문서를 지우며, **로컬 저장 데이터 삭제**를 선택하면 문서·공유 요청·설정을 모두 삭제합니다. 브라우저의 사이트 데이터 삭제로도 이 데이터는 지워집니다.

PWA 설치, 업데이트, 앱 파일과 폰트 수신에는 배포 사이트 연결이 필요합니다. 캐시 준비 뒤에는 앱 자산을 오프라인에서 사용할 수 있습니다. Chrome 확장의 링크 메뉴는 사용자가 직접 선택한 HTTPS URL을 열 때 그 사이트의 일회성 호스트 권한을 요청하고, 로그인 쿠키·자격 증명·리퍼러를 보내지 않습니다. URL 파일은 크기·지원 형식을 확인한 뒤 현재 브라우저 작업으로 가져옵니다.

이 앱은 광고, 분석 추적, 계정, 클라우드 동기화를 제공하지 않습니다.
