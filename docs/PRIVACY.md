# 개인정보 처리 안내

The Viewer는 사용자가 연 파일을 브라우저에서 해석하고 편집합니다. 파일 본문, 연락처, 일정과 첨부를 앱 서버나 분석 서비스로 업로드하지 않습니다.

## 확장과 PWA 사이의 파일 전달

Chrome 확장은 읽은 파일을 확장 전용 IndexedDB `the-viewer-extension-relay`의 `tickets` 저장소에 `ArrayBuffer`로 임시 보관합니다. 티켓에는 현재 탭 ID와 파일 메타데이터가 기록됩니다. 티켓은 10분 후 만료되고, PWA가 파일을 복원해 저장한 뒤 `COMMIT`을 보내면 삭제됩니다. 실패한 전달은 만료 전까지 다시 시도할 수 있습니다. 임시 저장 용량은 최대 300 MiB이며, 공간이 부족하면 오래된 티켓부터 정리합니다. 만료 정리는 Chrome 알람과 저장소 접근 때 수행합니다. 파일 본문은 `chrome.storage.local`에 저장하지 않습니다.

PWA는 `https://m00nlygreat.github.io/the_viewer/`에서 확장에 연결하고 브라우저 내부 포트 메시지로 192 KiB씩 요청합니다. 요청은 정확한 PWA origin·경로, 최상위 프레임, 티켓을 만든 탭인지 확인합니다. 파일명, 원본 URL, 로컬 경로와 본문은 PWA 주소에 넣지 않습니다. 일반 파일은 데스크톱 50 MiB, 모바일 20 MiB 제한을 적용합니다. 기존 작업 이전은 문서별 스냅샷을 사용하며 스냅샷은 최대 200 MiB입니다.

작업 복구가 켜져 있으면 PWA는 받은 문서를 사이트 origin의 IndexedDB에 저장한 뒤 티켓을 완료 처리합니다. 작업 복구가 꺼져 있으면 문서를 현재 탭 메모리에서 연 뒤 티켓을 완료 처리합니다. 일반 파일은 데스크톱 50 MiB, 모바일 20 MiB 제한을 적용합니다. 기존 작업 스냅샷은 데스크톱 200 MiB, 모바일 100 MiB까지 허용합니다. 파싱이나 저장이 실패하면 완료 처리하지 않아 만료 전 재시도할 수 있습니다. Chrome 확장에 저장된 기존 문서는 PWA 저장 확인 전까지 삭제하지 않습니다.

## PWA 저장과 네트워크

작업 복구가 켜져 있으면 열린 문서의 원본 바이트, 편집 상태와 테마 설정을 사이트 origin의 IndexedDB에 저장합니다. 설정에서 복구를 끄면 저장된 작업 문서를 지웁니다. **로컬 저장 데이터 삭제**는 문서·공유 요청·설정을 삭제합니다. 브라우저에서 사이트 데이터를 삭제해도 이 데이터는 지워집니다.

PWA 최초 방문과 서비스 워커 캐시 준비에는 네트워크가 필요합니다. 캐시 준비 뒤 앱 자산은 오프라인에서 사용할 수 있습니다. 확장과 PWA가 설치되어 있고 PWA 캐시가 준비되어 있으면 로컬 파일 전달은 오프라인에서도 가능합니다. PWA 업데이트는 사용자가 적용을 선택하는 방식이어서 전달 중 자동 새로고침으로 작업을 중단하지 않습니다.

## Chrome 확장 파일 감지

확장은 EML·CSV·Markdown·ICS·VCF 응답 자동 열기를 제공합니다. 이를 위해 `declarativeNetRequestWithHostAccess`, HTTP(S) 사이트 접근 권한과 로컬 파일 접근 선언을 사용합니다. HTTP(S) 최상위 GET 응답은 MIME, URL 파일명과 `Content-Disposition` 파일명을 확인하며 HTML 응답은 열지 않습니다.

HTTP(S) 자동 열기는 사용자의 최초 탐색 응답을 확인한 뒤 본문을 다시 요청합니다. 두 번째 요청은 쿠키·자격 증명·리퍼러를 보내지 않고 리다이렉트를 따르지 않습니다. 따라서 서버가 GET을 두 번 처리할 수 있고, 인증이 필요한 응답은 다시 요청할 때 읽지 못할 수 있습니다. HTTP 연결은 암호화되지 않습니다. 사이트 접근 권한을 제거하면 해당 사이트의 자동 열기는 작동하지 않습니다.

링크 메뉴는 사용자가 선택한 HTTP(S) 주소의 사이트 접근 권한을 확인하거나 요청한 뒤 파일을 가져옵니다. 이 요청도 쿠키·자격 증명·리퍼러를 보내지 않고 리다이렉트를 거부합니다. 로컬 파일 자동 열기는 Chrome의 **파일 URL에 대한 액세스 허용**을 사용자가 켠 뒤 작동합니다. 파일 본문은 기기에서 읽고 서버로 업로드하지 않습니다.

이 앱은 광고, 분석 추적, 계정, 클라우드 동기화를 제공하지 않습니다.
