## 2026-11-02

- 1280×720 검수 화면에서 값 버튼을 눌러 드래그 분리·빈 자리 재연결, 프로퍼티 컨테이너 분리·재연결, 최상위 객체 분리·루트 자리 재연결, 팔레트 값 칩의 캔버스 자유 배치를 직접 확인했다. 분리된 프로퍼티 행의 회색 배경과 미연결 값/객체의 출력 제외 상태도 화면에 반영됐다.
- 구조 캔버스의 격자 표시를 되살리고 격자 맞춤을 제거했다. 입력 요소 외에는 텍스트를 선택하지 않는다.

- 후속 피드백에 따라 팔레트를 왼쪽 사이드바로 되돌리고, 빈 캔버스에 칩을 놓으면 해당 좌표에 미연결 블록으로 자유 배치하도록 방향을 바꿨다. 미연결 블록은 실제 구조 출력에서 빠지며 컨테이너에 놓을 때 연결한다. 빈 바닥 드래그 pan과 smooth zoom/스크롤 전환을 적용한다.
- 깊은 중첩 사례를 다시 대조했다. `$.…`는 원본 값이 아니라 구조 경로이며 목업에서는 컨테이너 맥락으로 쓰인다. 렌더 조건이 깊은 스칼라 행에도 경로를 반복해 보여 주고 있어, 경로를 깊은 컨테이너에만 표시하도록 고쳤다. “이 그릇만 보기”는 깊은 중첩 목업에 있는 동작이라 유지한다.

- 컨테이너·프로퍼티·값 팔레트 칩을 같은 포인터 드래그 경로로 맞추고, 드래그 복제본을 원본 모양과 집은 위치 그대로 커서에 붙였다. 자유 배치 초안의 불필요한 회색 배경 래퍼를 제거했다.

- 초기화 뒤 팔레트 abc를 빈 캔버스에 놓자 `Cannot read properties of null (reading 'kind')` 오류가 실제로 재현됐다. 미연결 블록은 1개로 남고 새 블록은 커밋되지 않았다. 이 오류는 [기존 소스 점검](../mockup/review-source/source-audit.json)과 일치하므로 정상 드롭을 구현·검수할 필수 수정 항목이다. 드래그 기능 축소로 해결하지 않는다.
- 마지막 새로고침 시도에서 컴퓨터 사용 도구가 다시 현재 브라우저 URL을 확인하지 못해 조작을 차단했다. 이후 화면 입력은 중단했고 마지막 초기화 완료는 확인하지 못했다. 케이스 시트의 로딩·상단은 보았으나 8개 사례군 각각의 직접 조작은 미완료다.
- 창 캡처는 1920×1032, 편집기 preview 선언은 1440×980이다. 새 화면은 도구에서 확인했으며 이미지 파일로 저장하지 않았다. CSS computed style·IME·실기기 검수를 수행했다고 표시하지 않는다. 원본 목업 해시는 그대로이며 제품 코드·의존성은 변경하지 않았다.

## 2026-11-01 — 구조 데이터 편집 구현

- JSON은 `jsonc-parser`의 위치 기반 구문 트리, YAML 1.2는 `yaml` 2.9.1, TOML 1.0은 `toml-eslint-parser` 1.0.3의 구문 트리로 읽는다. 숫자 토큰과 JSON 중복 키 순서를 모델에 보존한다. 파서 인스턴스는 워커나 복구 저장소에 전달하지 않는다.
- 타입 메뉴는 값 표면의 보조 클릭과 Shift+F10으로 연다. 목업에서 진입 입력은 확인되지 않아 제품 연결 방식으로 정했다. 키는 깊이별 최소 너비를 사용하고 긴 이름은 160px에서 말줄임한다.
- 공통 헤더에 `가져오기`와 `출력 복사`를 두고, 파일 내보내기는 선택한 출력 형식을 사용한다. 다른 형식으로 출력해도 열린 문서의 형식과 저장 기준은 바꾸지 않는다. 같은 형식의 미수정 파일은 원래 바이트를 유지한다.
- 날짜·색 팝오버는 즉시 반영하고 연속 조작을 한 이력 단위로 묶는다. Escape 또는 바깥 클릭은 팝오버를 닫고 변경 복원은 Undo가 담당한다. 100개를 넘는 배열은 앞 3개와 마지막 항목 사이에서 나머지를 펼치거나 접는다.
- YAML의 앵커·참조, 블록으로 표현할 수 없는 태그, 복수 문서, 비문자열 키는 구조 변경과 변환 출력을 잠그고 원본을 유지한다. 일반 YAML 전체를 잠그지 않는다. TOML 문자열로 입력된 날짜는 같은 형식으로 저장할 때 문자열 타입을 보존한다.
- 브라우저에서 JSON 가져오기, 값 삭제와 빈 자리, 공통 Undo, 팔레트에서 객체로 드롭, TOML 미리보기, 날짜 체크 즉시 반영과 Undo를 확인했다. 전체 8개 시각 사례·CSS 치수 비교·Windows IME·실기기 터치와 복구 재시작은 이번에 직접 확인하지 않았다.
- 미완성 구조 초안도 문서 복구에 저장하도록 고쳤고, 빈 자리를 만든 뒤 브라우저를 새로 열어 복구되는 것을 확인했다. 값의 키보드 편집 시작·취소와 출력 형식 전환도 확인했다.
- 단일 값 변경은 원문 토큰의 위치와 지문이 유효할 때 해당 범위만 교체해 주변 공백과 주석을 보존한다. 구조를 다시 직렬화하면 이전 위치 정보를 폐기한다. TOML에서 표현할 수 없는 유니코드와 숫자 범위는 출력 전에 차단한다.
- YAML의 없는 참조와 순환 참조를 오류로 처리하고, 확장 프로그램에서 전달하는 구조 모델을 재귀적으로 검증한다. 깊은 중첩과 형식별 원문 보존의 회귀 사례를 추가했다.
- 전체 검사에서 테스트 95개와 PWA·확장 빌드가 통과했다. 이후 드래그 자기 대상·입력기 조합·캔버스 내부 입력 스크롤 경계를 보완하고 변경 파일의 린트·타입 검사, 두 빌드와 확장 ZIP 검사를 다시 통과했다. 8개 사례군 전체와 실기기 입력의 시각 검수는 완료로 기록하지 않는다.
