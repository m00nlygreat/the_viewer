# 용어

## 원칙

- 프로젝트 용어와 GUI 표시명은 합의된 내용만 등록한다.
- 버튼과 메뉴 이름은 화면 문맥을 확인한 뒤 정한다.
- 구조 데이터 용어는 [기준 목업](../mockup/JSON%20%EB%B7%B0%EC%96%B4%20%EB%94%94%EC%9E%90%EC%9D%B8.html)과 [구현 계획](../GOAL.md)을 따른다. 현재 제품 구현 완료를 뜻하지 않는다.

## 핵심 용어

| 내부/문서 용어 | GUI 표시 | 의미 |
| --- | --- | --- |
| 작업 공간 | 열린 파일 | 현재 열어 둔 문서와 이메일에서 따로 연 첨부 문서의 목록 |
| 렌더링·구조 편집 탭 | 보기 | 현재 작업본을 형식에 맞게 읽고 셀·블록·필드·상세 영역에서 편집하는 탭 |
| Markdown 연속 편집 | 보기 | CodeMirror 6에서 문서 전체를 한 번에 편집하고 비활성 구문 블록에는 즉시 서식을 표시하는 동작 |
| 구조 편집 | 편집 | 보기 안에서 선택한 내용을 수정하는 지역 동작. 별도 상위 탭으로 사용하지 않음 |
| 원시 텍스트 탭 | 원본 | 현재 작업본의 전체 텍스트를 표시·편집하는 탭. 데스크톱은 Monaco Editor, 모바일은 CodeMirror를 사용하며 불변 입력 백업과 구분 |

| 원본 파일 핸들 | 원본 파일 핸들 | 파일 선택·드롭·PWA 실행에서 얻어 동일 로컬 파일에 직접 저장하도록 문서에 보관하는 브라우저 핸들 |
| 기준본 복원 | 되돌리기 | 현재 파일을 마지막 저장·내보내기 기준본으로 복원. 한 동작을 취소하는 Undo와 구분 |
| 형식 표시명 | 이메일·표·문서·일정·연락처 | 각각 EML·CSV·Markdown·ICS·VCF를 가리키는 명령 메뉴 표시명 |

| 구조 데이터 블록 편집기 | 보기 | JSON·YAML·TOML이 공유할 팔레트·캔버스·출력·점검 화면. 별도 상위 탭을 만들지 않음 |
| 프로퍼티 행 / 배열 자리 | 이름 / 0 | 이름 또는 인덱스와 값 연결을 묶는 회색 행. 행 전체와 내부 값은 별도 드래그 단위 |
| 값 원문과 읽기용 정보 | 값 / 풀이 | 칩의 실제 값과 옆의 날짜·자릿수 설명을 구분. 풀이를 실제 값으로 저장하지 않음 |
| 값이 없는 자리 | 빈 자리 | 아직 값 블록이 연결되지 않은 편집 초안. 실제 null인 `없음`, 빈 문자열인 `빈 텍스트`와 구분 |
| 새 프로퍼티의 이름 미입력 | 이름 없음 | 이름을 입력하지 않은 편집 초안의 표시. 유효한 빈 문자열 키 `""`와 구분 |

| 분리된 블록 | 연결 안 된 블록 | 최상위 문서에 연결되지 않은 캔버스 블록. 파일 출력에는 제외하고 로컬 초안에 보존 |

## GUI 상태값

- `수정됨`: 현재 작업본이 마지막 저장·내보내기 기준본과 다른 상태.
- `시스템`: OS 테마를 따르는 설정. 라이트·다크의 명시 선택과 구분한다.

## 쓰지 않거나 주의할 표현

- `브라우저 안에서만 처리`는 파일 해석·편집을 기기 내부에서 수행한다는 뜻이다. 설치 자산 수신이나 사용자가 요청한 URL 파일 열기까지 네트워크가 없다는 뜻으로 확대하지 않는다.
- Blob 다운로드 요청을 `파일 저장 완료`로 표현하지 않는다. 실제 디스크 저장 여부를 확인할 수 없으면 `내려받기 시작`으로 안내한다.
- 큰 정수 안내의 GUI 문구는 `정확히 저장할 수 없는 크기 · 텍스트로 바꿀까요?`다. 도움말에서 숫자 원문 토큰은 그대로 출력되고 문자열로 바꾸면 자릿수를 문자열로 보존한다고 설명한다.
- 상위 문서 탭은 `보기 / 원본`으로 표기한다. `보기`를 편집 불가 상태로 해석하거나 `원본`을 불러온 당시의 백업으로 설명하지 않는다.
- 상세 동작 기준은 [요구사항](REQUIREMENT.md)과 [GOAL](../GOAL.md)을 따른다. 정적 목업의 타입 메뉴는 값 표면의 보조 클릭 또는 Shift+F10으로 연다.
